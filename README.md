# SolarVerseAI

**Intelligent Solar Platform for Homes and Solar Plants**

SolarVerseAI is an intelligent solar platform designed to help homeowners plan rooftop solar installations and help plant operators monitor and manage solar power plants.

Plan rooftop solar, estimate savings, monitor plant performance, and make smarter energy decisions.

## Features

### For Homeowners

- Solar potential and system planner
- Savings and ROI calculator
- Battery planner
- Energy forecasting
- Environmental impact analysis
- Saved reports

### For Plant Operators

- Solar plant monitoring
- Fault detection
- Generation forecasting
- Soiling analytics
- Predictive maintenance

> **Note:** Some modules currently use demo/sample data. Forecasts and health scores are estimates.

## Tech Stack

- **Frontend:** React 19, TypeScript, TanStack Start
- **Styling:** Tailwind CSS 4, shadcn/ui
- **Charts:** Recharts
- **Backend:** Supabase
- **Package Managers:** npm and Bun

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/SubhamC-gif/screenshot-match.git
cd screenshot-match
```

### 2. Install Dependencies

**Using npm:**

```bash
npm install
```

**Using Bun:**

```bash
bun install
```

### 3. Environment Setup

Create a `.env` file in the project root directory and add your Supabase credentials.

Example:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

> Never commit your `.env` file or expose secret API keys publicly.

### 4. Start Development Server

**Using npm:**

```bash
npm run dev
```

**Using Bun:**

```bash
bun run dev
```
